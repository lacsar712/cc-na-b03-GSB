# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 查找方案

总表的收窄条件（判词多选 + 灯号包含的一段文字）可存成命名方案，之后一键套用。套用后总表只留同时满足所有条件的行；一个都不中时表体为空并提示「没有相符灯」，不会把全部行铺回来。刷新后仍停在刚套用的方案上，点「清除方案」恢复全部。

- keeper（持灯账号）：新建、改名、删除方案，也可套用。
- watch（只读账号）：只能套用已有方案，不能新建、改名、删除。
- 删掉正在套用的方案后，总表自动恢复显示全部。

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. 用 keeper 存一个方案：判词只勾「不合格」，灯号文字填 09。一键套上后总表只剩 LH-09（偏暗种子），刷新后仍是它。
5. 把判词改成「合格」、灯号仍是 09 另存一个方案，套上后表体为空并提示「没有相符灯」，不会铺回全部行。
6. 删掉第 4 步的方案后，总表恢复可看全部；换 watch 登录能套用已有方案，但看不到保存表单，直接提交新建或删除会被拒绝。
